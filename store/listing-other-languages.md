# Fiches Chrome Web Store — autres langues (optionnel)

Le Chrome Web Store permet d'ajouter une fiche par langue (menu "Store listing" → langue en haut
de la page dans le Developer Dashboard). Les fiches complètes FR et EN sont dans
`listing-fr.md` / `listing-en.md`. Voici de quoi compléter rapidement les 3 autres langues
supportées par l'extension — au minimum le nom (inchangé) et la description courte ; la
description détaillée peut reprendre la version anglaise si tu ne veux pas tout traduire.

## Deutsch (de)

**Name:** Immotop Companion

**Kurzbeschreibung (max. 132 Zeichen):**
Blockieren Sie einen Verkäufer oder eine Agentur auf immotop.lu-Suchergebnissen mit einem Klick.

**Kategorie:** Produktivität

## Português (pt)

**Nome:** Immotop Companion

**Descrição curta (máx. 132 caracteres):**
Bloqueie um vendedor ou agência nos resultados de pesquisa do immotop.lu com um clique.

**Categoria:** Produtividade

## Lëtzebuergesch (lb)

Le Lëtzebuergesch n'est pas disponible comme langue de fiche dans le Developer Dashboard du
Chrome Web Store (liste de langues fermée gérée par Google). L'interface de l'extension reste
disponible en luxembourgeois une fois installée ; seule la fiche du store ne peut pas l'être.
